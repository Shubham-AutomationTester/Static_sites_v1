Render setupUse your existing Static Site
  1. Extract the ZIP. Upload the contents to the top level of your connected GitHub repository. index.html must be visible immediately, not inside another site folder.
  2. Use the settings below in your existing Render Static Site. You do not need a Blueprint or a Web Service.
  3. Save, then select Manual Deploy > Deploy latest commit. Open the URL shown on your Render service once it is Live.

Still seeing Not Found?

Check that GitHub has index.html at the repository root, that your Render Publish Directory is ., and that the latest deployment succeeded. Do not add a catch-all rewrite to hide missing pages.

No Node.js, Python runtime, environment variables, paid web service, or YAML is required by this package. Render's normal account usage limits still apply.

HTTP header setupOnly for the five X-Robots-Tag tests

In your Render Static Site, open the HTTP Headers configuration. Add these five rows, then save. Use exact paths, not a global /* rule. No terminal is needed.

The first three rows cover the basic header rules. The last two are edge/combination probes. These settings are added once in Render; the HTML file cannot supply response headers.
